Implementation

A general teacher, with specialist packs kept optional.

The general foundation is skills/teacher. The existing teach-pro-max entry delegates general lesson creation to it; preserved legacy state operations remain compatible. Neither new lessons nor their claims require a C program. Source facts and assumptions accompany the mathematical and qualitative models.

All formats derive from the same live lesson model: editable SVG/PNG still, explorer, layered Q&A, cards, narrated MP4 and interactive video with chapters, captions and model controls. The complete static lesson remains available without JavaScript.

Codex CLI

A quieter theme and a useful footer.

The installed configuration uses Catppuccin Mocha syntax highlighting, normal structured tool output, reduced animation, and a compact footer for model, context, usage limits and branch. It was exercised in a disposable 120 × 40 terminal without a model request. Existing sessions were not restarted.

Codex exposes syntax themes and status-line items. Arbitrary message-box borders, a custom header and full application recoloring are not established supported settings. The next normal launch will read the saved configuration. CLI setup, actual terminal evidence and rollback ↗
