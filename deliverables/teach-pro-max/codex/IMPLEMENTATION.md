# Implementation and limits

The general foundation is `skills/teacher`; `teach-pro-max` delegates ordinary teaching to it. Its preserved embedded distribution remains a compatibility component. The C development adapter is separate and uninstalled. This run used native Codex workers and bounded authenticated Grok routing batches; it did not consume Claude quota. A larger Grok content-review request timed out and earns no review credit. Cursor execution authentication was blocked; no credentials were reset or API fallback used.

The defects were in both the skill and generation. Product changes repaired mandatory-practice/default routing, crowded figures, audio peak handling, caption occlusion and compatibility-entry contradictions. Independent content review also found authored boundary wording, a missing relationship and clipped labels. Those outputs were repaired and rechecked. Source values passing a numerical audit did not excuse incorrect or incomplete explanation.

All modelled quantities, actual artifacts and strict failures have separate evidence. Valid-control acceptance is separate from planted-error detection, and the planted error must be the proposition identified by the blind reviewer. Small control sets and a single visual reviewer do not establish population reliability or human learning.

Four completed general candidates are versioned: ac6b65f, 3810ea4, fa2fa35, 0d20ff7. Their private evaluation uses the same sealed bank and thresholds. No governing checker or original test changed during these candidate runs. The one practice-regression adjustment was explicitly made and frozen in the preceding governing-only stage. The original/current teacher baselines are byte-identical; no baseline end-to-end artifact comparison is claimed.

The optional C source is 4a834ac. Its report records genuine remaining failures and method conflicts; synthetic claims unit tests are not four-lesson claims acceptance. No C integration, acceptance-rule relaxation or installation has occurred. The old public holdout remains regression data, and the fresh bank is kept out of Git and the public artifacts.

The fixed general release rule still requires every critical criterion. Actual human listening is unavailable in this runtime and remains NOT_RUN; no agent has pretended to hear the audio. The private review page supplies the real measured videos with blank human verdicts. Visual acceptance belongs to Prax. Neither a passed automated check nor a download is approval.

All new rendered media and archived working fixtures are release assets with hashes. Git stores source, reports and recipes. The existing historical binary archives were not moved or rewritten. The CLI UI changes are separately backed up, configured and verified; the general teaching candidate remains uninstalled.

The SVG text-bound input preflight rejects a clipped source before export. It is a product guard, not an independent truth/acceptance check. The final private measurement is 24/24 routing and 52/56 E2E criteria: the four missing listening verdicts keep release readiness false.
