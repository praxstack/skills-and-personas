1. **[P1] Stale passes survive rebuilds — `package/prax-teach/ptk/build.py:137–144,228`.** Before: partial builds did not inherit other media’s gates. After: matching lesson hash plus a nonempty directory imports old passes; `_artifact_list()` then replaces their hashes. Counterexample: corrupt `video/lesson.mp4`, run `--only still`; old video passes now attest to the corrupted file’s fresh hash. **Fix:** verify the complete previous artifact inventory and hashes before carrying gates; invalidate changed dependencies.

2. **[P1] Default verification loses sensitivity and controls — `package/prax-teach/ptk/verify/claims.py:599–642,806–835`.** Before: every selected mutation plus its control; thresholds were 100% value catches, ≥90% claim catches, ≥95% control acceptance. After: one caught mutation suffices. Counterexample: reviewer catches one numeric swap but accepts every false-mechanism mutation; full suite fails, selected numeric canary passes. Reproduced in memory. **Fix:** retain calibration requirements for `verified`; give canary-only runs a weaker status.

3. **[P1] Hard-link containment removed — `package/prax-teach/ptk/state/io.py:44–67,644,976`.** Before: `st_nlink != 1` rejected state files and locks. After: same-owner regular files pass with a warning. Counterexample: a private state file linked outside the workspace remains readable through that alias after workspace deletion; alias writes also bypass workspace locking. Ownership and `O_NOFOLLOW` cannot distinguish backup links from hostile aliases. **Fix:** restore rejection; handle legitimate linked files through an explicit migration to isolated inodes.

4. **[P2] Artifact metadata fabricates reviewer evidence — `package/prax-teach/ptk/verify/claims.py:126–135`.** Before: reviewers received the SVG’s location. After: matching `data-in` attributes produce “labelled as a wrong belief.” Counterexample: an empty `<g data-chrome="wrong_belief" data-in="x"/>` makes a misconception in box `x` appear labelled to the reviewer, although no label is rendered. **Fix:** require actual validated, visible label text and verified spatial association.

5. **[P2] Arbitrary axis values bypass verification — `package/prax-teach/ptk/verify/claims.py:48`.** Before: `axis-tick` was rejected as an unknown label. After: any matching number passes and is excluded from teaching review. Counterexample: change a tick from `1` to `999`; mapping accepts it, while value checks only validate fact-tagged values. Reproduced the mapping predicate. **Fix:** bind tick values and positions to an independently computed scale.

6. **[P2] Long-token heuristic can hide late speech — `package/prax-teach/ptk/verify/media.py:162–167`.** Before: offset used silence near the token’s end. After: tokens longer than 0.75 seconds use the last silence starting *inside* the token. Counterexample: token `[1,4]`, silence `[2,2.2]`, final silence starts `4.05`, cue ends `2`: measured offset changes **4.05 → 2**, falsely passing despite resumed speech. Reproduced in memory. **Fix:** verify that the chosen silence contains the token endpoint; otherwise preserve the later boundary or fail uncertain alignment.

7. **[P2] Caption control checks now trust a flag — `package/prax-teach/ptk/verify/visual.py:485–490,598–599`.** Before: checked browser track modes `showing → hidden → showing`. After: checks `data-on` values `true → false → true`, with the actual track always hidden. Counterexample: remove the CSS that hides captions when disabled; attributes toggle and text matches, so the control gate passes while captions remain visible. **Fix:** measure rendered visibility after each toggle.

8. **[P2] Morph gate shortens its own obligation — `package/prax-teach/ptk/verify/frames.py:341–343,364`.** Within this range, the original gate required output visibility until `reveal + outputs_at*k`; commit `270af89` changes that to `reveal + min(outputs_at, MORPH-0.05)*k`. Counterexample: old output fades after the shortened deadline but before replacement output arrives—previously failed, now accepted. The deadline also comes from the renderer’s own planner. **Fix:** independently require continuous readable output until replacement output is visibly present.

9. **Legitimate fixes:** `verify/claims.py:91–110` joins wrapped SVG text before sentence matching; `verify/frames.py:166` compares visited-line sets for a dot-based visualization; `verify/mutation_claims.py:62–69` fixes signed-number mutations and excludes replacement strings containing the original value.
