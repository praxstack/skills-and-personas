# Test Plan
Generated by /plan-eng-review on 2026-10-18.
Branch: main. Repo: local `prax-teach-evaluation-20261016/v2.1`.

## Affected artifacts (the "pages")
- **Still explainer** (SVG and PNG, wide and portrait, light and dark): values match the captured facts and the independent `expect` values. Digits read as lining numerals (OCR). No overflow at 390 or 1440 px. Contrast is at least 4.5 for text and at least 3 for rules.
- **Interactive explorer** (single HTML file): every input in its domain matches an independent function. It works with keyboard and mouse, the no-JS fallback is complete, and it makes no network requests.
- **Q&A expander:** layers open in order, wrong answers route to named misconceptions, and print expands every layer.
- **Flash cards** (.md and .apkg): answers equal the captured outputs, and the deck round-trips through genanki.
- **Narrated video** (MP4, WebVTT captions and chapters):
  - −16 ± 1 LUFS, true peak ≤ −1 dBTP;
  - every cue within 0.5 s;
  - WER ≤ 10% on non-code words;
  - 1080p30, H.264 plus AAC;
  - frames inspected.
- **Interactive video explorer:** pause, seek and chapter jump open the explorer at the last state already shown. Pausing 0.1 s before an answer cue reveals no answer text. The no-JS fallback shows the poster sequence and the transcript.

## Key interactions to verify
- Explorer: slider, number box (empty, non-integer, out of range), bit toggles by keyboard, the theme switch.
- IVE: play, pause, seek past the end, rapid scrubbing, chapter list, captions on and off, transcript click-to-seek.
- Q&A: expand one layer, expand all, print.

## Edge cases
- Non-printable codes 0–31 and 127, codes 128–255 (character set caveat), and plain `char` signed on this Mac.
- Kokoro missing gives a `say` fallback and status `degraded`. A missing whisper model gives sync `not-run` and status `incomplete`.
- Chrome blocked by the sandbox falls back to Docker `--network none`. If neither works, the gate is `not-run`.
- A claim that maps to no sentence, a sentence that maps to no claim, and malformed reviewer JSON or a refusal.
- A program with UB but no `undefined-behaviour` claim is blocked.

## Critical paths
1. An unfamiliar request (WP0: switch fallthrough) runs route → model → capture → still, video and IVE → every gate → `verified`, with no `not-run`.
2. Today's regression, "printf never changes the bits" for a `(double)` cast: the claims gate fails it with the real reviewer.
3. Tamper and mutation: 100% of value mutations and at least 90% of claim mutations are caught.
4. Packaging: a clean `HOME` per host (Claude Code, Codex, Hermes, OpenCode) shows exactly one entry, and rollback restores v2 plus the learner-state snapshot.
