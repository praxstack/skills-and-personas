### The 9 critical issues

- **T1.** The default "explain first, no quiz" style overrides the learner workspace's contract (one prediction, then wait), and nothing says which wins.
- **T2.** It stops when the learner says they're satisfied, and the default lesson collects no evidence.
- **T3.** "Show the finished state immediately" makes prediction impossible for traces.
- **V1.** A deliberately wrong figure (67, `0100 0011`, prints C) passes every gate and gets a `passed` receipt.
- **V2.** Bit tables render 0 and 1 as "o" and "ı", because Georgia's old-style numerals are the fallback.
- **M1.** The visual router can't see a video request ("narrated video" routes to `none`).
- **M2.** The mode router treats "make me a narrated explainer video about pointers" as an ordinary task.
- **M3.** There is no narration contract: no TTS, timing, WebVTT, chapters, loudness, audio description or pronunciation of code tokens.
- **M4.** Every motion job is downgraded to static, and the router never probes Manim or HyperFrames.

### Other structural findings

- The renderer can't emit inline SVG, math, Mermaid or `<video>`/`<track>`. The verifier rejects `.mp4`. The Visual Lab blocks media and has no time model.
- Figures break in dark mode and below about 400 px.
- The package's own visuals don't use its house style.
- Validation fails on every learner workspace unless you pass `--artifact-only`, and `--check` fails unless `SOURCE_DATE_EPOCH` is set.
- Hermes sees 25 `prax-teach-v2` skills and Codex loads 6 openspec skills.
- About 2 MB of the 12.9 MB install is product; 85% is history and duplication, hash-locked by the gates.
- The receipts attest to an older SKILL.md (hash 4a3380… against the current 41f373…), the smoke test forced its own result, and `configure.py` pins hashes of files it wrote itself.
- Advertised Socratic and quiz modes have no method. There's no misconception handling, no undefined-behaviour guard for C, and no exam-drill mode.
- Reading needed before the first teaching word: about 20k tokens, or about 35k with persistence.

## What the proofs showed (built outside the package)

The host stack can do all of this today. The package just doesn't route to it or verify it.

- **Still, explorer and flash cards** (`proof/still-interactive`): every value comes from real clang 21 and gcc-16 runs. 716 + 3,264 assertions pass and a tamper test catches 5 of 5 corruptions. Contrast passes AA in light and dark at 1440 and 390 px, and there's a 12-card Anki deck.
- **Narrated video** (`proof/video`): 71.8 s, 1080p30. Narration is local Kokoro TTS (`hyperframes tts`, af_heart) at −16.0 LUFS and −1.5 dBTP. Captions and transcript are WebVTT and every cue is within 0.44 s of plan. `hyperframes check` passes, contrast passes 43/43, and 11 frames were inspected.
- **A gap no check caught:** all three proofs say "printf never changes the bits; the format only decides how to read them". That's false for `printf("%f", (double)a)`: the cast creates a double with different bits. The value assertions passed. A separate check of the text's claims would have caught it.

### Host friction found by the proofs

- Kokoro needed a dedicated venv, `HYPERFRAMES_PYTHON` (no skill documents it), and a fix for a long-path bug in its pronunciation data.
- HyperFrames telemetry is on by default, `init` updates skills from GitHub unless `HYPERFRAMES_SKIP_SKILLS=1`, and the CLI auto-upgraded from 0.8.163 to 0.8.169 mid-run.
- There's no LaTeX, so Manim `MathTex` fails. Typst isn't installed either.
- HyperFrames render fetches Google Fonts even when fonts are bundled.

## Approach catalog (top 3 per type, from report 05)

1. **Still explainer:** SVG generated by code from captured data; Typst with CeTZ and fletcher; Graphviz from generated DOT.
2. **Interactive explorer:** step-through viewer over captured traces; a localhost compile-and-trace server for the learner's own code (clang, gcc-16, sanitizers); marimo for Python DSA.
3. **Q&A expander:** predict-before-reveal layers with wrong answers routed to named misconceptions; per-token "why" annotations in code (Shiki or Code Hike); folding callouts.
4. **Flash cards:** genanki and FSRS with answers taken from real runs; cards generated from trace states and SVG occlusion; code-writing cards checked by the compile server.
5. **Video explainer:** HyperFrames with Kokoro, driven by the trace; Manim CE with a local Kokoro voiceover service; VHS terminal recordings of real compiles.
6. **Interactive video explorer:** play the HyperFrames composition in-page so pausing hands over to the live explorer at the same state; MP4 with Vidstack and WebVTT cues that open the explorer at the cue's state; Scrimba-style replay into a live editor.

The cross-cutting recommendation is one lesson model. A trace and facts JSON captured from real compiled runs feeds all six artifact types and every check.

## Proposed direction (to be challenged)

Build Prax Teach v2.1 as a new, slim package beside v2:

1. **One lesson model.** A `lesson.json` holds facts (captured from real runs), claims (each with a stated justification and a source), a trace, and a storyboard. Every artifact is a projection of it.
2. **Six projectors:** still (SVG/PNG, light and dark, wide and portrait), explorer (self-contained HTML), Q&A expander, flash cards (Markdown and .apkg), narrated video (HyperFrames + Kokoro + WebVTT + chapters), and interactive video (in-page composition player with pause-to-explore).
3. **Correctness gates:**
   - value assertions against captured facts, plus a tamper test;
   - a claims review that reads every sentence against the claim list, run as an independent LLM pass with a rubric, so its result is a reviewed finding, not a proof;
   - contrast measurement;
   - screenshots at 2 widths in 2 themes;
   - ffprobe, LUFS and caption-sync checks for video.
4. **Routing fixes:** explicit medium words win; the workspace contract (AGENTS.md, MISSION.md, NOTES.md) beats skill defaults; prediction-first when the workspace asks for it; real host-tool probes (binaries, not just skill files).
5. **Teaching fixes:** Socratic and quiz methods that actually exist, misconception handling, a C undefined-behaviour guard, an exam-drill mode, evidence collected during lessons, and a token budget for the loader.
6. **Packaging:**
   - about 2 MB install, with history kept in a separate archive;
   - exactly one skill per host;
   - honest receipts produced by fresh runs;
   - pass on Node 22 and 24;
   - no `/Users/prax` paths;
   - telemetry off and `HYPERFRAMES_SKIP_SKILLS=1` set by the media scripts.
7. **Host setup** (needs Prax's OK where it installs software): Kokoro venv (done in the proof folder), BasicTeX or Typst for math, optionally whisper-cpp for caption checks.
