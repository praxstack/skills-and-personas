   434	
   435	**Data flow and shadow paths (capture → model):**
   436	- **Happy path:** compile with clang under the sandbox with warnings and sanitizers on (D17.4), run twice, the outputs match, and they're stored as facts with sha256 hashes next to the independent `expect` values. gcc-16 compiles the same source for diagnostics only.
   437	- **Missing input** (no source or program for a fact): `ModelError("fact X has no source")`. The build stops.
   438	- **Empty stdout:** stored as an empty-string fact. Allowed, but a value gate that expects text fails loudly.
   439	- **Upstream error:**
   440	  - a compile error gives `CompileError` with the compiler's stderr;
   441	  - a timeout gives `RunTimeout`;
   442	  - outputs that differ between compilers give `CompilerDisagreement`, which is valid when the behaviour is implementation-defined, but then a claim must say so;
   443	  - outputs that differ between runs give `NondeterministicOutput`.
   444	
   445	**State machine (lesson build):**
   446	
   447	```
   448	  draft ──capture──▶ captured ──project──▶ projected ──verify──▶ claims-pending ──claims check──▶ verified ──package──▶ packaged
   449	    ▲                   │ fail                │ fail                │ any gate failed
   450	    └──── edit ◀────────┴─────────────────────┴─────────────────────┘ (stays failed; never "verified")
   451	  Invalid: projected→packaged without verify (ptk refuses); verified with a not-run gate marked passed (schema forbids).
   452	```
   453	
   454	**Coupling.**
   455	- Projectors depend only on `lesson.json` and the style tokens.
   456	- Gates depend on `lesson.json` and the artifacts, never on how a projector works internally.
   457	- The C repo isn't a dependency; the capture runner is self-contained.
   458	
   459	**Scaling.** A build costs one TTS pass per scene (cached) and one HyperFrames render, about 2–4 minutes for 60–90 s of video. Ten lessons in a pack cost about 30 minutes. The first thing to break at 10x is TTS and render time, so a content-hash cache and `--only` flags per projector handle it.
   460	
   461	**Single points of failure.**
   462	- HyperFrames: a pinned local install (D17.9). If it's missing, video gates are `not-run` and the build is `incomplete`.
   463	- The Kokoro venv: falls back to macOS `say`, disclosed in the report.
   464	- Playwright: if it's missing, the visual gate reports `not-run`.
   465	
   466	**Security architecture.** No network endpoints. The capture runner executes C that the agent wrote, so it gets a temp dir, rlimits, a timeout, process-group kill, a resident-size watchdog and a tested `sandbox-exec` profile (no network, no writes outside the temp dir). If `sandbox-exec` is missing, capture refuses to run (D17.10). Explorer and IVE HTML are self-contained, with a CSP meta tag that blocks all remote fetches.

   469	
   470	| Integration | Failure | Handled by |
   471	|---|---|---|
   472	| HyperFrames | Global CLI upgrades itself mid-build (seen today) | Pinned local install (D17.9); the global CLI is never used |
   473	| Kokoro | Long-path bug in its pronunciation data (seen today) | Venv setup applies the proven fix |
   474	| Playwright | Browser cache purged by an outside cleaner (seen on 2026-10-08) | `PLAYWRIGHT_BROWSERS_PATH` set to the package's own state dir |
   475	
   476	**Rollback.** v2.1 installs alongside v2 under a candidate name. Acceptance flips the `prax-teach-v2` symlink, and rollback flips it back: one command, about 1 second.
   477	
   478	**Beautiful version.** One file, the lesson model, is the only thing an author writes. Everything else is a pure function of it, plus captured runs. A new engineer reads `lesson.schema.json` and the six projector files and understands the whole system.

   517	  CompileError/RunCrashed  | Y        | stop; show stderr and exit status              | exact compiler message
   518	  RunTimeout               | Y        | kill process group; stop                       | "ran >5s, killed"
   519	  NondeterministicOutput   | Y        | stop; show both outputs                        | diff of the two runs
   520	  CompilerDisagreement     | Y        | require a claim of kind implementation-defined | which compilers disagree
   521	  ModelSchemaError/RefErr  | Y        | stop; JSON pointer to the bad field            | "/facts/3/source missing"
   522	  LayoutOverflow           | Y        | fail the gate; screenshot path                 | screenshot + element id
   523	  TTSUnavailable           | Y        | fall back to `say`; build status `degraded`    | "TTS: say (Kokoro missing), degraded"
   524	  NarrationEmpty           | Y        | stop                                           | scene id
   525	  RenderCheckFailed        | Y        | stop; keep hyperframes output                  | lint/runtime lines
   526	  MediaGate/Loudness       | Y        | fail; numbers in report                        | measured vs target
   527	  GateNotRun(*)            | Y        | report not-run with reason; build not verified | "sync: not-run (no transcriber)"
   528	  ClaimsReviewInvalid      | Y        | retry once with schema reminder, then fail     | raw reviewer output path
   529	  ClaimsUnmapped           | Y        | fail; list sentences                           | the unmapped sentences
   530	```
   531	
   532	No catch-all handlers: every error class is distinct, and `ptk` exits 1 for a gate failure, 2 for host or environment problems and 3 for model errors.
   533	
   534	**D7.1.** `GateNotRun` never counts as passed, and a build with any not-run gate is reported `incomplete`, not `verified`. *Accepted*, completeness 10. This is the direct fix for the v2 habit of passing on presence.

   435	**Data flow and shadow paths (capture → model):**
   436	- **Happy path:** compile with clang under the sandbox with warnings and sanitizers on (D17.4), run twice, the outputs match, and they're stored as facts with sha256 hashes next to the independent `expect` values. gcc-16 compiles the same source for diagnostics only.
   437	- **Missing input** (no source or program for a fact): `ModelError("fact X has no source")`. The build stops.
   438	- **Empty stdout:** stored as an empty-string fact. Allowed, but a value gate that expects text fails loudly.
   439	- **Upstream error:**
   440	  - a compile error gives `CompileError` with the compiler's stderr;
   441	  - a timeout gives `RunTimeout`;
   442	  - outputs that differ between compilers give `CompilerDisagreement`, which is valid when the behaviour is implementation-defined, but then a claim must say so;
   443	  - outputs that differ between runs give `NondeterministicOutput`.

   446	
   447	```
   448	  draft ──capture──▶ captured ──project──▶ projected ──verify──▶ claims-pending ──claims check──▶ verified ──package──▶ packaged

   454	**Coupling.**
   455	- Projectors depend only on `lesson.json` and the style tokens.
   456	- Gates depend on `lesson.json` and the artifacts, never on how a projector works internally.
   457	- The C repo isn't a dependency; the capture runner is self-contained.

   459	**Scaling.** A build costs one TTS pass per scene (cached) and one HyperFrames render, about 2–4 minutes for 60–90 s of video. Ten lessons in a pack cost about 30 minutes.    462	- HyperFrames: a pinned local install (D17.9). If it's missing, video gates are `not-run` and the build is `incomplete`.

1. **Offline setup is incomplete (E1–E3, D19.2).** The download inventory omits Playwright’s browser revision, HyperFrames’ browser, Kokoro’s voice file, and any Docker image. `PLAYWRIGHT_BROWSERS_PATH` doesn’t configure every Chrome launcher. **Fix:** enumerate and pin the complete runtime dependencies; prove a first build succeeds with empty ordinary caches and networking disabled. 2. **A local npm pin doesn’t disable HyperFrames updates (D17.9, E3).** The environment contract omits `HYPERFRAMES_NO_UPDATE_CHECK=1`. Upstream documents background update behavior. **Fix:** set it explicitly and test that pinned **0.8.169** neither fetches nor modifies its installation. [HyperFrames documentation](https://github.com/heygen-com/hyperframes/blob/main/docs/packages/cli.mdx).

3. **ET1’s network evidence is insufficient.** “MP4 produced, zero denied requests in the render log” cannot distinguish successful isolation from missing denial logging. Docker isolation also doesn’t automatically report attempted requests. **Fix:** require deliberate DNS, HTTPS and child-process canaries to fail observably; specify the actual Docker invocation carrying `--network none`.

4. **Caption synchronization lacks an independent timing oracle (D17.8, E2).** Comparing cue starts with their *planned* times can pass captions and audio that drift together. **Fix:** measure synthesized segment durations before scheduling; compare final-MP4 speech timestamps against VTT starts **and ends**. Include shifted-audio, truncated-speech and wrong-code-token fixtures.

5. **Claims reviews can become stale approvals (D18.1).** Schema validation doesn’t establish that a review covers the current lesson, artifacts, sources or rubric. **Fix:** bind each job and response to an immutable input manifest; invalidate affected reviews after edits. Test replaying a previously passing review against changed content.

6. **The sanitizer test exercises the wrong mechanism (Eng §3).** `printf("%f", a)` should trigger the format-warning gate; it doesn’t demonstrate working runtime sanitizers. **Fix:** separate warning-only, runtime-ASan and runtime-UBSan fixtures. Specify GCC’s diagnostic-only command separately from Clang’s compile/link/run flags. Clean sanitizer output must never mean “no UB.” [Clang UBSan](https://clang.llvm.org/docs/UndefinedBehaviorSanitizer.html).

7. **The stated CSP conflicts with self-contained interactive HTML (§3).** `default-src 'self' data:` blocks ordinary inline scripts and styles. **Fix:** define explicit script/style hashes and media/font directives; choose and test the delivery mode, including metadata-track loading. Exercise the packaged artifact with CSP enforced. [CSP behavior](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy).

8. **`ptk selftest` cannot independently complete its own claims tests (E3, Eng §3).** A Python CLI cannot invoke unspecified host-subagent facilities merely because `claims-jobs/` exists. **Fix:** define the host orchestration adapter and resume protocol. Distinguish automatic selftests from agent-mediated integration tests; test both on each supported host.

9. **Mutation detection has no adequate false-positive control (D17.5).** A reviewer that rejects almost everything can achieve excellent mutation recall. **Fix:** pair every corruption with a valid control, require a clean-control acceptance threshold, and distinguish schema rejection from detection of the intended semantic error.
