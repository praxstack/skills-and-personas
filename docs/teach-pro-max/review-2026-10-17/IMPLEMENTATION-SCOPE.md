# What the remaining implementation changes

Status: planning scope, not an implementation or acceptance claim. User authorizes autonomous engineering review and completion of all four outcomes. The proposed six-hour execution cap remains unanswered. Do not start a newly budgeted candidate or describe evaluation inputs as newly frozen before that decision.

## Product behavior

Teach any requested subject through a complete explanation of a bounded idea. Choose tools available in the current host. Continue with deeper explanation, alternate examples or another medium when requested. Respect the learner's choice to stop. Optional assessment does not define the finish line.

## Default appearance

Use AskTheMove's readable print plus short handwritten coach annotations. Apply warm paper, purposeful arrows and semantic ink colors. Keep mathematical relationships, code and longer text precise and legible. Synchronize drawing with the explanation when animation is supported. Preserve immediate access to the completed figure, replay controls where applicable, reduced-motion behavior and learner style overrides.

Provide reusable production guidance and the smallest suitable local presentation assets. Reuse the existing renderer for compatible static pages. Do not force HTML, one drawing library or a video service on every host. Static sanitization must remain strict; richer artifacts use an explicitly supported delivery path rather than enabling arbitrary script in Markdown.

## Course and notes

Separate the learner's course map from the explanation being taught and from notes for later use. The map records useful prerequisites, topic relationships, current location and optional next directions. It stays editable. The notes preserve definitions, worked reasoning, assumptions, limitations, questions and sources. Link matching lessons and visuals. A one-question session does not require a complete course folder. Follow existing lesson-save and explicit save-nothing rules. Personal progress and preferences remain separately consented.

## Correct activation

Ordinary tasks remain ordinary. Editing a lesson is not a request to be taught its topic. Creating a course as teaching material remains teaching intent. Explicit learner requests and mode overrides retain precedence. Add exact public regression cases, then inspect the broader intent precedence instead of adding a patch for each phrase.

## Integration and delivery

Reuse existing secure continuity storage, static renderer, media selection guidance and canonical symlink installation. Keep historical evidence unchanged. Produce current evidence bound to final source bytes and preserve the original installation for rollback. Independent review and actual teaching/render checks must pass before installation. A worked example used for verification is not the product itself.
