# Subscription evaluation contract v2

Versioned amendment to EVALUATION-CONTRACT-v1.md and DESIGN-v1.md. Original documents, offline evaluator, baseline package and historical receipts remain unchanged. User approval to revise the incompatible evaluator is recorded in APPROVAL-2026-10-16.md. This amendment changes evaluation transport and evidence retention, not the product specification or acceptance thresholds.

## Approved transport

Use existing authenticated Codex subscription inference; provider network access is permitted. No paid API purchase, subscription change or new remote service is authorized. The trusted broker may read its private temporary authentication file. It sends only the fixed teaching bundle and the current/past teaching conversation to inference, with no answer key, rubric, grader instructions or other arm outputs. Model shell/read, browser, MCP, app, image-generation and delegation features are disabled. The apply_patch helper remains exposed by this CLI, so CLI read-only mode rejects model writes; any helper event fails transport. The trusted CLI also runs under an outer filesystem profile denying hidden/source/other-arm file-data reads and outside writes. No unrelated MCP/tool configuration is inherited. Global host configuration is unchanged.

The exact implementation is tools/teaching-evaluation/subscription_runner.py, with its JSON/CLI formats documented in the adjacent README.md. Both arms receive their own SKILL.md and the same declared reference path set: references/MODE-CONTRACT.md, TEACHING-PROTOCOL.md, VISUALIZATION-ROUTER.md, ARTIFACT-CONTRACT.md, LEARNER-STATE.md. Per-file bundle hashes and complete source-snapshot hashes are retained. Bundle text is capped at 200,000 UTF-8 bytes without truncation. Package snapshots exclude only .git, .venv, node_modules, __pycache__, .pytest_cache, .mypy_cache, .ruff_cache and .DS_Store; exclusions are recorded identically for both arms. Original historical source is not deleted or modified.

Each arm/replicate gets independent workspace, temporary CODEX_HOME and generated output paths. Only existing auth.json is copied (0600; private directory 0700); normal completion and exceptions remove it. An abrupt host kill may require manual removal of teach-auth-* temporary directories. Auth bytes are never intentionally placed in prompts or receipts. The broker is trusted with its private authentication home. The outer OS profile denies /Users file-data reads except the current arm workspace, private CLI home and executable, denies /Volumes and /private/tmp, and denies /private/var except the private CLI home. Outside writes are denied except /dev. Metadata and system runtime reads remain allowed. These measured rules cover the documented /Users receipt layout; no claim of a universal runtime allowlist is made.

Real sequential user/assistant calls use explicit role replay: each inference sees only actual prior turns and one new user turn. Future turns are never exposed early. This is not a native persisted CLI thread and does not preserve model tool/session filesystem state. Deadlines apply across all turns of each arm, use equivalent paired model/configuration, and kill the whole process group on timeout. Errors, unexpected tool events, empty responses or changed source/package bytes fail transport. Failed transcripts and actual response/source artifacts remain available.

## Explicit coverage limit

The broker measures teaching content and adaptation under tool-unavailable conditions. It can deliver actual textual Markdown, SVG and HTML source for separate rendering and inspection; it cannot prove that the model executed a renderer, saved a lesson, read/resumed learner state, or respected runtime filesystem permissions through tool use. Prompts explicitly forbid fictional tool/file/inspection claims. Real consent, withdrawal, state integrity, no-write and security behavior must pass separate runtime CLI integration/regression tests. Tool-less refusal never substitutes for those tests. Secondary-host smoke remains a separate four-public-scenario requirement when usable; unavailability limits portability claims.

An initial strict OS runtime allowlist aborted the CLI. A narrower private-file denial profile authenticated successfully. Shell-disable paired controls showed a positive shell tool call/disclosure and a negative no-call/no-disclosure result; an additional probe discovered that apply_patch remained exposed and could create a harmless file under workspace-write. The final broker therefore combines that working outer profile with CLI read-only mode, disabled read/execution features and strict rejection of tool-event transcripts. Source/other-arm read and outside-write probes, failures, and the trusted auth-home allowance remain diagnostic receipts. The earlier workspace-write experiment is not the accepted broker boundary. The final combined boundary must be independently reviewed from exact flags/configuration and live adversarial JSONL before bank freeze. No model tool events are permitted; any observed event invalidates transport. No hidden inputs are used during public setup diagnostics.

## Independent scoring and unchanged gates

An independent evaluator seals six unseen scenario families and grading keys outside candidate-visible workspaces, exports only teaching-only id/turns JSON, then inspects frozen retained outputs using the original five dimensions: mechanism/meaning, story coherence, visual purpose, concrete-to-general connection, learner control/adaptation. Each dimension remains 0–2, anchored as v1; total 0–10. Rubric assessment replaces term matching. Grading keys never enter teaching prompts. Evidence of generated source is not rendered inspection; actual controller rendering/inspection receipts remain required.

All numeric/product gates from v1 remain unchanged: six families, three paired repetitions, at most 36 primary target runs; candidate overall mean at least 8/10; each scenario three-run mean at least 7/10; no zero candidate dimension; overall paired gain at least 1; no scenario-mean regression; at least five of six scenario means improve. No protected critical failure; all applicable deterministic regressions pass; representative actual rendered inspection passes. Record all repetitions and ranges. Four secondary public smoke scenarios; at most two candidate revisions; 120 minutes from first candidate edit through evaluation per candidate; stop at budget or after two no-gain candidates. No unplanned repetitions, threshold reductions or automatic promotion.

The transport always emits scored:false and accepted:false. Independent scoring and actual inspection cannot be omitted. The runner's aggregate_scores function applies unchanged numeric gates only to a complete independent 36-record matrix plus explicit nonnumeric gate receipts; it does not invent rubric scores. Hidden eligibility is contingent on an independently reviewed frozen boundary/configuration and sealed bank. A public smoke is never held-out evidence, and an engineering evaluation is never evidence of human learning.

## Freeze and preservation

Receipts, bank and scoring materials live outside the package they attest to. Freeze runner/configuration/bundle/bank hashes before candidate edits. Candidate workers may not inspect bank or grader keys or change evaluator gates. Original baseline and current accepted version are identical for the first candidate. Future comparisons and fresh-bank requirements remain as v1. Installed links and learner directories remain untouched during setup; promotion and rollback requirements remain as v1.

Pre-freeze integrity clarification: initial imports still reject all symlinks/hardlinks. Final integrity compares exact file hashes and path sets and rejects symlinks, but tolerates nlink-only increases and records source link counts before/after. Setup observed public source/package files acquire link count 2 with no content changes; the cause is unknown. The controller approved this distinction before freeze. External hardlink alias creation alone will therefore not fail final integrity; no inode-immutability claim is made. This does not relax hidden/source/other-arm read denial or model-write restrictions.
