# Publication preparation

This phase prepares the reviewed teacher and teach-pro-max source for both public
repositories. It changes delivery navigation and publication glue only. Runtime,
governing files, historical archives, demonstrations and their receipts stay intact.

The secondary repository receives exact tracked skill trees from this commit. Its
external export manifest records source provenance, membership, hashes and modes;
its portable CI does not duplicate the primary repository sandbox qualification.

Remote review, checks, merge and post-merge installation verification are recorded
separately. This preparation commit does not establish publication or activation.
