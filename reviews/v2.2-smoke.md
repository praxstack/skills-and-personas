## Per request

### E1 still: `smoke-lessons/struct-padding`
- `layout.c` prints sizeof, the offsets and a byte map (`c...iiiiss..`). It ran clean under sanitizers. 17 facts, 0 expectation mismatches. 10 claims with 5 stored N2310 passages. Validate passed on the first try.
- Build 1 (exit 1, 3 s): `KeyError: 'title_claim'` at still.py:719. The schema makes `figure.title_claim` optional, but the still requires it.
- Build 2 (exit 1, 2 s): `KeyError: None` at still.py:736 (`MECH_W[kind]`). `mech.panel_kind` returns None for a lesson with no panel that isn't a switch program. The report shows `error.internal: true`, but the CLI exits 1, which SKILL.md's table reads as "a gate failed".
- Stopped there. The only fix would be a panel kind, and views, stack and neuron would each misrepresent struct layout.

### E2 explorer: `smoke-lessons/twos-complement-char`
- 5 programs: `char_wrap.c` (127 + 1), three knob values, and `int_overflow.c` (`ub: true`, `run: false`). Views panel with a UB lane, `values` knob. 13 passages.
- Build 1 (15 s) failed `explorer.layout`. The reason was worded for the switch explorer ("n=1 brk=None"). Build 2 reached claims-pending. Build 3 was a truth fix: neither compiler gave a warning for INT_MAX + 1, so the claim "compiled for its warnings" was false.
- Smaller frictions: `needs_hedge` matches only lowercase "on this machine". LESSON-MODEL.md doesn't say the explorer needs `figure.panel`.

### E3 Q&A: `smoke-lessons/sizeof-array-pointer`
- 8 layers. Captured output: `20 8`, `4`, `5`, `30`. Validate passed on the first try.
- The route conflicts with itself: `first_turn` says answer and `end_turn: true`, but `build_needed` is true. Taken literally, the build never happens.
- `sizeof_abi` has no `int*`, so `void*` stood in (an LP64 assumption). `qa.py` refuses a storyboard with no question that has options, although the docs call `options` optional. The page's layers differ from the chat layers TEACHING.md names. SKILL.md's "about 2 minutes" was 8 s here.

### E4 cards: `smoke-lessons/int-promotion-cards`
- The two prediction cards come from real runs: `-1 < 1u` prints 0, and the sum of two unsigned chars (200 and 100) prints 300. Expects are `printf_d`. 8 cards, 15 claims, 9 passages.
- Clang's `-Wsign-compare` would fail capture on the classic variable form, so the program uses literal constants. A program that has a question card gets no output card. True cards show no "Why".
- The schema makes `figure` optional, but validate requires it once `key_nodes` exist. SKILL.md's delivery list leaves out `build/cards/*`.

### E5 video: `smoke-lessons/sum-loop-trace`
- The video projector handles a lesson with no panel: the classic code-plus-output layout, a 110 s MP4, captions and 8 chapters. The total appears only after the adding steps.
- Build 1 (190 s) failed 7 gates, including `claims.mapping` ("sum = 11" in `vars` is "code text not in any program"), `ive.explore-return` (fell to the switch model), `ive.predict-gated` and `video.sync`. Builds 2 (139 s) and 3 (155 s) left the 3 gates in the table. Stopped after two repairs.
- The lexicon has no spoken form for `<`, `+` or `+=`, and `spoken` is retired, so narration had to be reworded to pass sync. `ive.predict-gated` plays only about 10 s past the question. An empty VARIABLES column is still drawn.

### E6 interactive video: `smoke-lessons/factorial3-ive`
- 7 trace states, 9 scenes, a stack panel, every expectation from an expect fn. `states.vtt` drives pause-to-inspect.
- Build 1 failed `ive.explore-return` with an empty reason. Adding a `calls` explore (programs for n = 1, 2, 4, 5) gave build 2: all 20 automatic gates passed and 11 claims jobs were written.
- No `mutations.json` was needed. The build made automatic value swaps.

## Docs that disagree with the tool
1. LESSON-MODEL.md still documents narration `spoken`. The schema calls it retired and validate refuses it.
2. The schema makes `figure`, `figure.title_claim` and question `options` optional. The still, validate and qa each require them.
3. VERIFY.md says a lesson with `figure.panel` declares a step-through IVE. The gate demands `figure.explore` (D23.5).
4. SKILL.md exit 1 means "a gate failed", but internal crashes also exit 1.
5. SKILL.md quotes "about 2 minutes": the page builds took 3-15 s and video+ive took about 3 minutes.
6. SKILL.md's qa-expand row ("layer-1 answer", end turn) collides with `build_needed: true` for an artifact request.
7. Undocumented limits found only by failing builds: code lines of about 40 characters at 390 px; `vars` values must be literal program text; the explorer and IVE need `figure.explore`.
