# The teaching loop

The loop runs until the learner says they're satisfied. Each pass makes the picture sharper or the understanding deeper. None of it is a script to recite: skip what the learner already has, slow down where they're stuck.

## 1. Find the gap

- Start from what they said. "Teach me X" from someone who uses X daily is a different lesson from the same words from a beginner. Read the vocabulary they used.
- Ask one question only when the answer changes the lesson. Good: "Have you seen derivatives?" Bad: a five-question placement quiz.
- In a series, the journal tells you: open threads, what's still unclear, which explanations already failed.
- Name the outcome in one sentence. "You'll be able to explain why June is warmer than December without mentioning distance."

## 2. Picture it

- Lead with a picture of the thing itself, not of the explanation. The beam on the ground, the request hitting the cache, the weights on the wires.
- Concrete before abstract: one traceable example, then the general rule. Use real computed numbers when relevant and sourced context for qualitative subjects.
- Quantitative pictures come from a checked model. Qualitative pictures can select and compare sourced examples, roles or context without pretending those are measured numbers.

## 3. Offer manipulation and optional practice

- Explain the whole mechanism before optional practice. Leave controls available so the learner can inspect another case without answering a question.
- Only in explicitly requested `practice-first` style, offer the attempt before revealing the worked answer. The learner can ask to be shown it or stop practice at any time.
- One hint per miss. After a second miss, or "just show me", teach it directly from a different angle. No shame in either path; both get recorded.

## 4. Explain why and how

- The why: the reason it has to be this way (the same light spread over more ground means less per square metre).
- The how: the mechanism, step by step (the tilt moves where the sun is overhead, which changes the angle, which changes the spread).
- Tie each sentence to something on the picture. If a sentence has no place in the picture, either the picture is missing something or the sentence isn't needed.
- Then map it to the formal version the learner will meet next: the equation, the code, the term of art. Say it's the same idea in other clothes.

## 5. Check

- Use a fresh case, not the one just shown: new numbers, a new place, a twist. Recognition of the example isn't understanding.
- Prefer "predict, then see" and "explain it back in your words" over multiple choice.
- A check is evidence for you, never a verdict on them. Wrong answers are the most useful data in the session.
- Viewing a lesson is not evidence of learning. If they skipped the check, the state is "unknown", not "learned".

## 6. Repair, or go deeper

If something's still unclear, change one thing (see the repair ladder in SKILL.md) and keep a list of what was tried. Signs it's still unclear:

- they can repeat the words but not apply them to a new case
- right answer, wrong reason
- "I get it" followed by a question that shows they don't
- they go quiet, or ask the same question again in other words

If it's clear, offer the next rung. Don't climb automatically.

## The depth ladder

| Rung | The learner can... | Typical medium |
| --- | --- | --- |
| L0 intuition | say what happens and roughly why, with a picture in mind | still, short animation, analogy |
| L1 mechanism | trace the steps that make it happen | explorable, step-through diagram |
| L2 formal model | use the equation, code or formal argument and connect it to the picture | explorable with the formula live, code panel, Manim |
| L3 edge cases and limits | say where it breaks, what the assumptions are, what changes at extremes | explorable at extreme settings, counterexamples |
| L4 transfer | use it on a problem they haven't seen, in another domain | new problem, practice-first |

Say which rung you're on ("this is the intuition; want the actual formula?"). Many learners are satisfied at L1. That's a valid finish if they say so.

## 7. Where to next?

Close every lesson with the learner's choice, not yours: go deeper, another example, explain it differently, practise, or done. The explorable page does this and produces a report: read it. Misses, reveals, and the explanations tried tell you exactly where the next pass should go.

The thread closes only when the learner says it does. Then give a one-screen recap (the picture, the claim, the why, one formal line) and, in a series, add a recall point for a later session.

## Understanding versus recognition

| Looks like understanding | Is it? |
| --- | --- |
| right answer on the example just shown | no, that's recall |
| right answer on a fresh case, with a reason | yes, at that rung |
| can explain it back using the picture | probably; check one fresh case |
| can say where it breaks | yes, at L3 |
| "makes sense!" | unknown; it's a feeling, not evidence |
| uses it unprompted later | yes, the best sign there is |
