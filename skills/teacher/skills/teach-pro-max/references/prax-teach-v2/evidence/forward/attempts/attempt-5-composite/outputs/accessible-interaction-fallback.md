# Accessible interaction fallback

## Hash-table load-factor practice — Round 1

This practice runs in chat. It needs no pointer, JavaScript, animation, or timer. The same instructions and data remain available as the complete static version.

Keyboard actions: type `A`, `B`, `C`, or `D`. You can also type `hint`, `skip`, `reset`, `I don’t know`, or `Answer now`.

Given:

- Load factor: \(\alpha = n/m\)
- Stored entries: \(n = 6\)
- Buckets: \(m = 8\)
- Resize only when \(\alpha > 0.75\)

Which result is correct?

- A. \(\alpha = 0.60\); keep the table
- B. \(\alpha = 0.75\); keep the table
- C. \(\alpha = 0.75\); resize now
- D. \(\alpha = 1.33\); resize now

What’s your choice?
