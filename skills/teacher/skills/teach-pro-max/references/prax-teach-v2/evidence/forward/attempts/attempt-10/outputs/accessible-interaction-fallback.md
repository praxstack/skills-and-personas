# Hash-table load-factor practice

This practice runs in host chat with no custom controls or scripts. Reduced-motion mode is inherent: there are no animations or transitions. The complete static path is the plain-text prompt below. There is no timer or automatic advance.

The host UI’s keyboard navigation, focus visibility, reduced-motion behavior, and assistive-technology support remain unverified.

## Round 1 — Threshold boundary

An open-addressed hash table has:

- Capacity: 16 slots
- Live entries before the operation: 11
- Operation: insert one new, unique key
- Resize check: after the insertion
- Resize rule: resize when the load factor is at least 0.75

**Action 1 — Calculate:** Find the load factor immediately after the insertion.

**Action 2 — Decide:** Should the table resize?

**Action 3 — Reply:** Type:

`LOAD = [equation] = [decimal]; RESIZE = YES or NO; BECAUSE = [brief reason]`

You may instead type `I DON'T KNOW — HINT 1` or `ANSWER NOW`.
